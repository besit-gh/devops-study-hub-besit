# DevOps Study Hub — русская локализация

Интерактивная локальная платформа для обучения DevOps и SRE: 23 темы, 91 структурированный урок, 455 вопросов для тестов и 184 вопроса для подготовки к собеседованиям.

![DevOps Study Hub](docs/screenshot.png)

## Возможности

- ИИ-наставник с потоковыми ответами по текущему уроку.
- Песочница для Bash, Python и YAML.
- Тесты с интервальным повторением по алгоритму SM-2.
- Подготовка к собеседованиям с оценкой ответов и объяснением ошибок.
- 10 практических проектов с Kubernetes, IaC, GitOps, Helm и ELK.
- Учебный маршрут, прогресс по модулям, XP, серии занятий и экспорт прогресса.
- Справочные карточки с командами.

Данные обучения хранятся локально. Регистрация и подписка не требуются.

## Требования

- Python 3.12+
- Node.js 18+
- npm 9+
- Git

Поддерживаются Linux и macOS. На Windows запускайте проект через WSL2 (Ubuntu). **В WSL2 рекомендуется хранить репозиторий в Linux-файловой системе** — например, в `~/projects`, а не под `/mnt/c/`: установка пакетов, сборка и работа с большим количеством файлов обычно заметно быстрее.

## Быстрый запуск в Linux / WSL2

### 1. Клонируйте репозиторий

    mkdir -p ~/projects
    cd ~/projects
    git clone https://github.com/besit-gh/devops-study-hub-besit.git
    cd devops-study-hub-besit

### 2. Один раз подготовьте окружение

    bash setup.sh

Скрипт создаёт виртуальное окружение Python, устанавливает зависимости backend и frontend и создаёт `backend/.env` из шаблона. Повторный запуск безопасен; зависимости frontend устанавливаются по lock-файлу через `npm ci`.

### 3. Запустите приложение

    ./start.sh

Откройте в браузере Windows или Linux: **http://localhost:5173**.

- Интерфейс: http://localhost:5173
- API и проверка backend: http://localhost:8000/docs
- Остановка обоих серверов: `Ctrl+C` в терминале запуска.

В WSL2 frontend слушает `0.0.0.0:5173`, чтобы его можно было открыть из браузера Windows. Backend по умолчанию привязан к `127.0.0.1:8000`.

### ИИ-функции (необязательно)

Уроки, тесты, проекты и справочные материалы работают без ключа API. Для ИИ-наставника и оценки ответов:

1. Откройте файл `backend/.env`.
2. Укажите свой `OPENAI_API_KEY`.
3. Перезапустите приложение.

Использование OpenAI API оплачивается отдельно согласно вашему тарифу. Приложение не выполняет автоматический перевод учебного контента и не отправляет его на перевод при запуске.

## Запуск через Docker

Если Docker установлен:

    cp backend/.env.example backend/.env
    docker compose up --build

Ключ API считывается backend из `backend/.env` и не встраивается в образ.

## Переменные окружения

| Переменная | Обязательна для ИИ | Значение по умолчанию | Назначение |
|---|---|---|---|
| `OPENAI_API_KEY` | Да | — | Ключ OpenAI API |
| `OPENAI_MODEL` | Нет | `gpt-4.1-mini` | Модель OpenAI |
| `VITE_API_URL` | Нет | `http://localhost:8000` | Адрес backend; задаётся в `frontend/.env` |

## Важно о безопасности

Песочница запускает реальные команды на вашем компьютере. **Не открывайте приложение в публичный интернет без дополнительной защиты**: изоляции сети и контейнеров, ограничений системных вызовов и проверки модели угроз. По умолчанию приложение предназначено для локального использования.

## База данных и прогресс

В репозитории есть предварительно заполненная база `backend/hub.db`. Прогресс сохраняется в ней же. Перед переключением веток экспортируйте прогресс на странице статистики.
